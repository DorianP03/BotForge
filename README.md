# BotForge
BotForge est mon atelier en ligne dédié à la conception et à la fabrication de projets robotiques. Vous y trouverez une sélection de prototypes, d’expérimentations mécaniques et électroniques, ainsi que des réflexions autour de l’innovation technique. Chaque projet est documenté pour partager à la fois les réussites et les apprentissages.
